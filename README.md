## 三个熟悉的时刻

- 你把一套课程讲稿、一沓学科笔记存进文件夹，告诉自己「以后系统学」——三个月过去，文件夹再没打开过；
- 深夜读一篇硬核长文，卡在一个没见过的术语上，切出去搜完回来，已经想不起上一句在说什么；
- 你把自己懂的东西整理成文档发给别人，对方回复「收藏了」——然后就再也没有然后。

学不完，多数时候不是内容不好，是**阅读的形态，和人的理解方式错配了**。公众号排版解决美观，解决不了门槛；AI 生成的长文解决产量，解决不了「读到一半卡在一个词上」。

## 为什么读不完：两个被验证的结论

**一、跳着读，人会迷航。** 超文本研究的奠基综述（Conklin, 1987）把「迷航」（disorientation）与「认知开销」（cognitive overhead）列为自由跳转阅读的两大经典代价；Edwards & Hardman（1989）的实验进一步证实，读者在纯非线性文本中显著迷失——你「搜完回来不知道读到哪」的体验，是被记录了三十多年的老问题。

**二、人是按故事逻辑读的，不是按知识板块读的。** 认知科学家 Daniel Willingham 的论断广被引用：「故事在心理上是特权结构」（stories are psychologically privileged）——人对因果链、时序链的记忆与理解，远强于对并列知识点的记忆；Kintsch 的阅读理解模型同样表明，读者靠叙事链条构建「情境模型」，知识板块只是搭进链里的素材。

## 双层结构：叙事管主线，抽屉管深度

把「读的层」和「查的层」拆开，各干各的事：

| 层 | 形态 | 职责 |
| --- | --- | --- |
| 主线 | 叙事章节，一章接一章 | 顺着故事逻辑读，防迷航 |
| 深度 | 术语抽屉 · 概念图谱 · 自测 | 按需展开，不打断 |

```
遇到不懂的词 → 点它 → 抽屉里看定义、要点、相关概念、原文出处 → 关掉 → 接着读
```

抽屉里的相关概念本身还能再点，一层层跳下去，`Esc` 原路返回。这个形态不是新发明：游戏圈叫它「P社手册」（Paradox 的 nested tooltips），口语里也叫「点读手册」，学名**渐进披露**（progressive disclosure）。

## 从「收藏」到「学完」

- 一套知识库，变成一本人人能点开学完的手册——不再是收藏夹里吃灰的链接；
- 一个 HTML 装下全部：离线、零依赖、微信直接发，十年后双击照样打开；
- 阅读进度自动存档，随时中断，随时回来；
- 读完有自测兜底——「收藏了」从此变成「学完了」。

这是一个 AI Agent Skill：你说一句「把布迪厄做成知识手册」，它完成内容设计、拼装、自动验证，交付这个 HTML。

## 核心体验

### 1. 点词即释，不打断阅读

解释永远是右侧叠加层：没有弹窗、没有强制跳转。概念卡里的相关概念本身也可点，可以一层层跳下去（抽屉里再开抽屉），`Esc` 或 `←` 随时原路返回。

![术语抽屉](assets/screenshots/bourdieu-drawer.png)

### 2. 概念图谱：看一眼知识长什么样

全部概念按语义分成六组着色，用力导向图连成网络，可拖拽、可调关系密度。读者迷航时回图谱看一眼全貌，再决定往哪走。

![概念图谱](assets/screenshots/bourdieu-graph.png)

### 3. 从零基础到自测，一条完整动线

| 模块 | 作用 |
| --- | --- |
| 分层章节（1~6 层，每章标注预计时长） | 零基础按层递进 |
| 术语速查表 | 中英对照，复习用 |
| 常见误区 | 提前拆掉读者会踩的坑 |
| 自测 | 读完验证，不是白读 |
| 阅读进度 | 每章一个「标记已读」，存在浏览器本地，随时中断随时回来 |

### 4. 单文件、零依赖、双击即开

一个 HTML 装下全部：章节、概念数据、图谱、测验。没有外部请求、不需要服务器、发微信发邮件都行，十年后打开还能用。

## 快速开始

**安装**（任选其一）：

```bash
npx skills add Tim-builder/progressive-handbook
```

或把本仓库克隆进你的 Agent skills 目录（`.zcode/skills/`、`.claude/skills/` 等均可）。

**使用**——对你的 Agent 说一句话：

> 帮我把「布迪厄」知识库做成一本渐进式披露型知识手册

> 把这套新员工培训资料做成渐进披露式的交互学习页

Agent 会完成内容设计、拼装、自动验证，产出：

```
<工作区>/<主题名>知识手册/<主题名>知识手册.html
```

## 它是怎么生成的

```mermaid
flowchart LR
    A[主题 + 素材<br/>知识库/讲稿/文章] --> B[术语先行<br/>30~40个概念 成对关联]
    B --> C[章节正文<br/>自然使用术语 触发自动链接]
    C --> D[拼装单文件骨架<br/>逻辑代码零改动]
    D --> E{自动验证}
    E -- 死链/占位符/术语不足 --> C
    E -- 全绿 --> F[交付<br/>章节数/术语数/阅读建议]
```

与传统「写完再说」相反，本 skill **先设计术语网络，再写章节**——章节正文里自然地用到这些词，自动链接才会生效，图谱的边才有据可依。

## 边界与承诺

- **不做公众号排版**，不做没有术语层的普通静态长文——那不需要这个 skill。
- 内容忠于用户素材，不编造事实；转述外部知识时在概念卡注明出处位置。
- 素材含未授权私密内容时拒绝写入；不覆盖已存在的交付目录。
- 验证不过且无法定位原因时停止并报告，**不带病交付**。
